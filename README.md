## Featured Projects

### 🗃️ mini-redis *(WIP)*
A from-scratch distributed key-value store in C++, built to understand systems programming deeply.
- Custom TCP server with **epoll**-based event loop
- **RESP protocol** parser (Redis wire format)
- **Consistent hashing** for key distribution
- **WAL** (Write-Ahead Log) for durability
- Design patterns: Strategy, Decorator, Composite, Visitor, Chain of Responsibility
